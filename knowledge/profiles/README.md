# Profile-targeted AIDOS knowledge

This directory is reserved for reusable knowledge whose applicability is tied to one or more versioned AIDOS profile presets.

Examples include evidence-backed recurring:

- stack/runtime constraints;
- hosting/deployment behaviour;
- product-archetype validators;
- integration failure signatures;
- capability-specific repair strategies;
- exposure/risk checks.

Knowledge here must reference applicable preset IDs/versions and retain provenance. A profile lesson may not silently override verified project truth or a human-accepted Definition.

Prefer promotion toward executable prevention:

```text
CANDIDATE profile lesson
→ PROVEN
→ preset/knowledge update
→ validator/tool when feasible
```

See `docs/PROFILE_PRESETS.md` and `schemas/profile-evaluation.schema.json`.
